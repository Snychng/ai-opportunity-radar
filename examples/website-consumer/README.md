# 网站消费端参考

这是不依赖构建框架的数据接入示例，不代表正式网站已经部署。将 `aor export` 生成并校验的 `public.v1.json` 复制到本目录后，使用仅绑定回环地址的本地 HTTP 服务打开。不要把内部 report、证据库或审核日志复制到这里。

页面提供六方向筛选、任务搜索、当前/历史状态、复核日期、详情抽屉和稳定 ID 的链接；所有来源文字通过 textContent 写入。手机端切换为横向行业导航。未知可选字段忽略，未知状态保守显示，非 1.x 的数据拒绝。真实项目应在发布流水线中使用 `aor export --validate ... --consumer`，不以浏览器基础检查替代完整契约校验。

正式接入时保留自身框架和样式，参照本例的数据读法以及 `types/public-v1.ts`；可改用 index + details 分页加载。状态按 publication_status 和 freshness 判断，不能把全部 items 都渲染成推荐机会。目录为空要区分未完成研究和证实无需求。生产 HTTP 缓存应绑定导出 revision，原子更新全部视图。
